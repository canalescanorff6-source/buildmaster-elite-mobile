# BuildMaster Elite Tático v34.00 — Studio Premium

A v34.00 reconstrói a interface do aplicativo sem alterar os motores de fichas, OCR, habilidades adicionais, Ímpetos e Mega Calibração v32.

## Principais mudanças

- tema único azul-marinho/grafite com contraste alto;
- menu lateral à esquerda preservado;
- guias e abas com conteúdo visível e navegação clara;
- Jogadores, Meu Time e Partidas protegidos contra dados incompletos;
- avisos globais compactos, sem cobrir a tela;
- textos secundários reduzidos no celular;
- áreas avançadas carregadas somente quando abertas;
- cache renovado somente na mudança de versão.

Use `npm run ci:verify` antes de publicar.
