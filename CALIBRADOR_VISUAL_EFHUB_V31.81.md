# BuildMaster Elite Tático v31.81 — Calibrador Visual eFHUB

## Objetivo
Permitir que o usuário posicione manualmente, sem digitação, os oito quadrados de leitura sobre o print do perfil eFHUB.

## Áreas
1. Nome + estilo
2. Carta / foto
3. Bio + condição
4. Posições + overalls
5. Boosters / ímpeto
6. 26 atributos
7. Modelo físico
8. Habilidades

## Funcionamento
- Toque numa área para selecioná-la.
- Arraste pelo centro para mover.
- Arraste os quatro cantos para redimensionar.
- Use setas e controles de tamanho para ajustes finos.
- Trave áreas já posicionadas.
- Salve o mapa proporcional para reutilizá-lo em outras resoluções.
- O botão “Ler com os quadrados ajustados” força o perfil eFHUB e usa exatamente o mapa definido.

## OCR interno preservado
O usuário ajusta somente oito blocos grandes. Internamente o app continua dividindo atributos em três colunas, modelo físico em três colunas e habilidades em linhas e cápsulas/janelas de contingência.

## Persistência
O mapa é salvo por conta, incluído no backup e restaurado junto das demais calibrações.
