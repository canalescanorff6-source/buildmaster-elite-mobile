# BuildMaster Elite Tático — Reformulação Visual v37.10

## O que foi reformulado
- nova base visual dark premium com azul profundo e contraste mais limpo;
- superfícies, painéis e botões com aparência mais sólida e menos neon;
- melhoria de legibilidade em títulos, textos auxiliares e placeholders;
- ajustes de hover, bordas e estados ativos para deixar o app mais consistente;
- novos textos nas áreas principais para ficar mais claro e profissional.

## Principais textos atualizados
- Início → Central
- Usar Imagem → Ler print
- Manual Pro → Criar manual
- Ficha do jogador → Resultado
- Registro do jogador → Cofre
- Menu e atalhos com descrições mais objetivas.

## Migração visual
A chave de migração da interface foi atualizada para aplicar o novo padrão visual premium por padrão,
preservando preferências funcionais como densidade, escala de texto, animação e desempenho.
